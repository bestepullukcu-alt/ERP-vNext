# Assumptions and boundaries

1. One person-day remains eight person-hours, inherited from the predecessor effort baseline. It is a planning convention, not measured duration.
2. The existing Shipment backend reserve explicitly includes narrow rework; the Root R2 application envelope fits within it in every O/M/P case.
3. The existing Shipment Test/VER reserve includes real-Auth/browser verification. Root-specific browser regression is a marginal subset and is not charged again as an independent end-to-end programme.
4. Independent runtime VER and browser regression remain separate deliverables even though they draw from the same reserve.
5. Candidate preparation is historical and has no reliable actual-hours record. It receives neither invented delivered-hour credit nor a new remaining estimate.
6. The estimate assumes the candidate semantics and three target source hashes remain unchanged. Drift or expanded scope requires successor estimation.
7. The report preserves all unaffected module estimates and the predecessor portfolio arithmetic.
8. Root R2 emission does not resolve the separate Load root-access design and implementation gap.
