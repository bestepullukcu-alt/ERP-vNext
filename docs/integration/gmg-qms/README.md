### Why v1 is superseded

It has 16 columns and is keyed on `full_path` alone. The counterparty identified that as
their own mistake: a path is not a permanent identity, so a folder rename would break
every record pointing at it, with no way to repair the link. Version 2 adds `folder_id`
(the permanent key) and `lifecycle_status`.

It is kept because it is the file that was actually run through the dry-run import, and
that run is the evidence behind two measurements: 103 rows import cleanly, and fourteen
were refused by our own folder-name minimum before it was lowered to two.
