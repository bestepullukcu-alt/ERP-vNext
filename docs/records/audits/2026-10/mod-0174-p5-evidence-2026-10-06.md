## 1. What was written

- **30 resx files** — `Resources/Views/Traceability/{Lots/LotsIndex, Lots/LotFieldIndex, Serials/SerialsIndex,
  LotMovements/LotMovementsIndex, LotTrace/LotTraceIndex, LotMigration/LotMigrationIndex}.{fr,es,zh,ar,ru}.resx`. Each
  is the `.en.resx` file with only the `<value>` contents replaced (generator: en file as template → same header, same
  key order, same layout, BOM, CRLF; values XML-escaped). Skeleton check: en and ar with values stripped are
  byte-identical.
- **SharedResource.{fr,es,zh,ar,ru}.resx** — only the five keys `Nav.Module.LOTSERIALTRACKING`, `Nav.Page.LOTS`,
  `Nav.Page.SERIALS`, `Nav.Page.LOTTRACE`, `Nav.Page.LOTMIGRATION` appended before `</root>` (`git diff --stat`: +5 / −0
  per file, no other line touched).
- **en / tr unchanged**; no code, view, JS, manifest, service, gateway or FU01 resx change.
- **Terminology.** The WP glossary for lot / serial terms (module, page titles, Lot, Lot No, serial, expiry, retest,
  manufacturing date, manufacturer / supplier lot, country of origin, CoA, lot and serial statuses, on hand, genealogy,
  backward / forward, reason, DataMatrix, registered / manually entered lot). FU01 Stock Ledger wording wins where FU01
  already translates the concept: the 7 stock statuses, the 15 movement types, "Stock Ledger", movement history, stock
  status, warehouse / location, product / SKU field, source, transaction date, searching, no results.
- **Language rules.** ru: counts phrased neutrally ("Партий: {0}", "Движений: {0}") — no plural infrastructure. ar:
  natural Arabic, no page-level RTL CSS (the layout's `dir="rtl"` does the work). zh: Simplified, full-width punctuation
  (`：`, `，`, `（）`, `。`). Placeholders `{n}`, `—`, `→`, `·`, `…`, error codes and `W-UI-02` / `MOD-0194` references
  kept as in en.
