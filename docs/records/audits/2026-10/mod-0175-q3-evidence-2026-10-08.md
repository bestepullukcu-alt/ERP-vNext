### 1.1 Item 4 — the already-published template version under E4 (measured)

- Q2 measured that Platform stores `DefinitionJson` verbatim incl. `signatureRequired / signatureMeaning`.
- E4 reads the step flags **at every instance start** from the pinned active version (`StartWorkflowInstanceHandler.cs:114` `FromVersion(activeVersion)` → `:188` `SignatureRequired = firstStep.SignatureRequired`). So a version published **before** E4 needs **no new version**: every instance started after E4 carries the flag (probe: template prepared → task `signatureRequired`, unsigned WorkCenter approve 409).
- Not covered: tasks created **before** E4 have `SignatureRequired = false` (field default) and stay approvable without a signature until decided; and E4's publish check (active meaning) never ran for a pre-E4 version — if a tenant deactivates `APPROVE`, its tasks cannot be signed (signing refuses an inactive meaning). Both → OPEN O-Q3-3.
