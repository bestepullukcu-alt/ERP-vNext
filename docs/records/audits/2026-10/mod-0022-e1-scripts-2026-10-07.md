# WP-0022-E1 — runtime probe ve sabotaj kaynağı (2026-10-07)

> Kanıt: `mod-0022-e1-evidence-2026-10-07.md` §5–§6. Depoya kod olarak eklenmedi (tek seferlik çalışma zamanı
> kanıtı). Probe: iki dosyayı boş bir klasöre koyun, AuthService ve Platform API projelerini derleyin,
> `DITEN_ITEST_MONGOD_BIN_DIR` ayarlıyken `dotnet run -- <worktree> <çıktı klasörü>` çalıştırın. Probe kendi mongod'unu
> (replica set, rastgele port) ve 15056/15057 portlarını kullanır; 27017'ye dokunmaz; veritabanları `itest_e1_probe_*`.
> Şifre ve bilet her koşuda rastgeledir ve hiçbir yere yazdırılmaz.

    Log($"SUMMARY: {results.Count(r => r.Ok)}/{results.Count} checks passed");
    File.WriteAllText(Path.Combine(outDir, "probe-transcript.txt"), transcript.ToString());
}
return results.All(r => r.Ok) ? 0 : 1;
