## 3. What F5 delivers (measured in code)

**Backend (InventoryService).**
- `previewEvidence` — period `q` / `d30` / `ytd` / `custom` (≤ 366 days, not after today), warehouses, types; four sections: KPIs (the F4
  `ExpiryKpiFormulas`, shared with the dashboard, not a copy), the period's exceptions (resolution, reason, signature id), policy changes,
  FEFO bypasses.
- `createEvidenceExport` — renders CSV (`;`, BOM, CRLF, formula guard) or PDF, stores the BYTES (`expiry_evidence_files`) and the log row
  (`expiry_evidence_exports`) in one transaction, `sha256 = SHA-256(bytes)`; same idempotency key → 200 with the same export (same file,
  same hash); key reused with another body → 409; audit `expiry.evidence.exported`.
- `getEvidenceExportFile` — the stored bytes; another company → 403, unknown → 404 `EXPIRY_EVIDENCE_EXPORT_NOT_FOUND`.

  tr / en (Accept-Language), footer "Şirket · Dönem · Oluşturulma · Sayfa n / N". Fonts only from the package's embedded Segoe WP bytes via
  `ExpiryEvidencePdfFontResolver` (Platform's resolver pattern, copied); every value a literal text run.

**Web.**
- `/Expiry/Exceptions` — tabs Tümü / Açık + İnceleniyor / SLA Geçti / Sonuçlanan with the server's totals, server DataTable, filters;
  "İstisna aç" only with `expiry.exceptions.create`.

- `/Expiry/Evidence` — preview, PDF / CSV download (create → the stored file), export log with `sha256:41d07f…e9b3` and a copy button.
- Bands: movement form outbound FEFO (state from `getFefoOrder` on `onSourceChanged`; reason field; Block mode disables submit; the 422s
