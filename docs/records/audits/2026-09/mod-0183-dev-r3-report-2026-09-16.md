## VER-04 root cause and correction

runtime_probe.py call() retained the caller's mutable body dictionary.
Later quantity/note mutations changed six previous records. The recorder now
parses Request.data immediately after HTTP request construction and stores that
independent snapshot. Absent bodies remain null. The response, status, schema
checks and service behavior are unchanged.

test_runtime_capture.py executes the actual call() function extracted from the
probe's AST, avoiding its top-level runtime scenario. A mock transport captures
the serialized bytes; after call(), the test mutates nested quantity and note.
The record must still equal parsed sent bytes and preserve its original values.
A separate test preserves no-body/null behavior.

contract_regression_probe.py now asserts exact invalid/accepted request values,
statuses and boundary count before writing evidence. sent_body_probe.py captures
Request.data separately at urllib.request.urlopen, then compares all 33 records
for method, path, body, idempotency key and status. It retains no auth token.
This is a client transport-boundary comparison, not packet capture and not
independent VER acceptance.

verify_evidence.py adds only the explicitly authorized R3 report to its bounded
allowlist and required complete set; all existing integrity checks remain.
