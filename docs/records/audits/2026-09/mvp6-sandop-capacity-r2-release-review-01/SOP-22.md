These are observable error and input-eligibility changes even where method/path, success schema and wire `v1` remain identical ([R2 annex](../mvp6-sandop-capacity-amendment-r2-01/sandop-capacity-semantics-v2.0.0-rc.2.md), [contract freeze rule](../../../../analysis/contracts/README.md)).

Clients with exhaustive error-code/status handling, old fixture assumptions or optimistic sign-off/evaluation flow can break. A minor additive classification is therefore unsupported. A `2.0.0` metadata label **does not** create a new URL, header negotiation or consumer migration while routes and wire `v1` remain shared.
