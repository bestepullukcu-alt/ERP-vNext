# Subscription Plan Catalog User Manual

Use Platform > Subscription Plans to define plans that can be assigned to tenants.

## List

The list shows plan identity, status, commercial terms, and availability. Use search and filters to narrow the list.

## Create And Edit

Create or edit a plan to define its display name, status, billing cycle, pricing fields, included modules, limits, and feature availability. Required fields are marked in the form.

## Features

Plan feature mappings decide which subscription features are available for the plan. Updating feature mappings affects future entitlement and availability checks that consume plan configuration.

## Activation

Activate plans that are ready for tenant assignment. Deactivate plans that should no longer be offered while preserving existing history.
