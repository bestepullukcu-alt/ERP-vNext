# Platform Account User Manual

Use Platform Account pages to review and update your own platform profile and settings.

## Profile

Open Platform > Account > Profile to review your account details. Update editable fields and save changes.

## Settings

Open Platform > Account > Settings for platform account preferences exposed by the current UI.

## Snapshot Refresh

If profile details appear stale after an update, the application can invalidate the local profile snapshot and reload the current account information.
