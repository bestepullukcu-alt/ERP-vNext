# Platform Admin Password & MFA Security User Manual

Use Platform account and security flows to keep platform administrator access protected.

## Profile And Security

Open your Platform Account pages to review profile information and any available security settings. Password and MFA challenge behavior is enforced by the authentication service.

## MFA

When MFA is enabled for a platform administrator, complete the verification challenge during login. Failed or expired challenges require a new login attempt or a fresh challenge.

## Support Notes

If a platform administrator cannot sign in, check account status, invitation state, MFA configuration, and tenant/platform login policy before resetting credentials.
