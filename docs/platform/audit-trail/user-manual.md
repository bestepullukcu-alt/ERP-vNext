# General Audit Trail User Manual

Use Platform Audit pages to review, export, redact, and manage retention for platform audit records.

## Audit Log

Open the Audit Log page to search and filter audit events. Select an event to inspect details and redaction state.

## Export

Use export when you need an offline audit extract. Exports are limited by configured row and date-window limits.

## Retention

Use Audit Retention to review and update retention policies. Retention changes should be coordinated with compliance requirements.

## Redaction

Actor redaction removes or masks personal data for the selected actor according to the implemented redaction flow. Use it only for approved privacy or compliance requests.
