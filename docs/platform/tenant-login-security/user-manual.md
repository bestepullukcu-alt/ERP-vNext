# Tenant Login & Security User Manual

Use the Tenant Security page to control login behavior for a tenant.

## Open Security Settings

From Platform > Tenants, open a tenant and select the Security page or security section.

## Edit Settings

Update the available login and security controls, then save. The exact fields are controlled by the current Tenant Login Settings form and may include login availability, restrictions, or security policy values.

## Operational Notes

Changing login settings can affect user access immediately. Review tenant support tickets and rollout timing before applying restrictive policies.
