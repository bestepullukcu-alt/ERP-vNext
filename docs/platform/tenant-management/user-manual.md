# Tenant Management User Manual

Use Platform > Tenants to manage tenant companies, lifecycle state, branding, administrators, login settings, subscription, and module access.

## List

The tenant list supports search, status, region, paging, sorting, KPI cards, row actions, and bulk deletion. Use the row actions to open details, suspend, reactivate, or delete a tenant.

## Create Tenant

Open Add Tenant and fill in the required tenant identity and contact fields. The tenant is created as a platform-managed record and can then be configured from the Details page.

## Details

The Details page groups tenant information into operational sections:

- Overview and identity
- Branding
- Admin users
- Security and login settings
- Commercial subscription and module entitlements
- Quota governance, where available

## Lifecycle Actions

Suspend blocks normal tenant operation without deleting the record. Reactivate restores an eligible suspended tenant. Delete uses soft delete and should be used only when the tenant record is no longer needed.

## Commercial Tab

Use the Commercial tab to assign or review subscription plans and module entitlements. Subscription plan assignment is the main source for plan-based access. Manual module entitlements are handled separately from plan-derived access.
