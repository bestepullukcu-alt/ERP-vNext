## NE (CrmService; Platform/FU01 DEĞİŞMEZ)
1. **Domain (additive):** `ContentSetRevision`'a nullable `RenderedArtifact` value object: `{ Guid ContentId, string Checksum, string MediaType, long ByteSize, string FileName, DateTimeOffset RenderedAtUtc, string RenderedBy }`. Snapshot/review alanları **mutasyona uğramaz**; yalnız bu alan + (varsa) küçük bir `RenderedAtUtc` marker. Class-map/serileştirme (yeni tipin BSON kaydı — [[crm-new-aggregate-classmap-guid]] tuzağı: ContentId GUID subtype).
2. **Application — `RenderContentSetRevisionCommand(revisionId, correlationId)` + handler:**
   - Revizyonu tenant-scoped yükle; **`ReviewStatus == approved` değilse → 409** (yalnız onaylı revizyon render edilir; reason code `content_set_revision_not_approved`).
   - **Idempotent (AT05 retry no-dup):** `RenderedArtifact != null` ise → mevcut artifact DTO'yu döndür, **yeniden render/upload YOK** (revizyon immutable → deterministik).
   - Aksi halde: `IContentSetRevisionRenderer.Render(revision)` → `(byte[] bytes, string fileName, string mediaType="application/pdf")`; `IContentArtifactStore.StoreAsync(scope=ContentMessagingArtifacts, owningItemId=RevisionId, owningVersionId=<deterministik: RevisionNumber'dan türet>, companyId=<JWT company claim varsa yoksa Guid.Empty>, fileName, mediaType, bytes)` → `{contentId, checksum, byteSize, mediaType}`; `RenderedArtifact`'ı set et; **optimistic concurrency** ile persist; audit `content_set_revision_rendered` (counts/correlation only, PII yok).
3. **Application contracts (seam):** `IContentSetRevisionRenderer` (Application katmanında arayüz) + `IContentArtifactStore` (Application) + sonuç DTO'ları. Handler yalnız seam'lere bağlı (test edilebilirlik).
4. **Infrastructure:**
   - `PdfSharpContentSetRevisionRenderer : IContentSetRevisionRenderer` — MigraDoc ile deterministik tek-doküman: başlık (RevisionCode/RevisionNumber), ContentSet kimliği+versiyonu, Template adı, Scope özeti, SelectedComponents listesi, SelectedClaims listesi, EligibilitySnapshot özeti, tenant + üretim zamanı. Çıktı geçerli **%PDF**. **Headless font resolver gotcha:** Linux'ta font çözümü için `IFontResolver` gerekebilir — additive ekle (dev Windows'ta sorun yok, go-live notu).
   - `HttpContentArtifactStore : IContentArtifactStore` — `HttpCrmAuditPublisher` header-forward desenini aynala (`Gateway:BaseUrl`, kullanıcı `Authorization`+`X-Tenant-Id`+`X-Correlation-Id` forward), `POST /api/v1/document-repository/objects` multipart. **Fail-soft DEĞİL:** 2xx değilse anlamlı hata fırlat (401/403→yetki, 5xx/timeout→503 profili); render komutu bu hatada başarısız olur ve `RenderedArtifact` yazılmaz.
   - DI kayıt (`DependencyInjection.cs`).
5. **Api — `ContentSetRevisionsController`:**
   - `POST objects/{id}/render` (veya mevcut route deseni) — RBAC **yeni `crm.content-set.render`** (tanımla + seed notu; SCMM-16A grant deseni) — `RenderedArtifact` DTO döndür (`contentId, checksum, byteSize, mediaType, renderedAtUtc, renderedBy`). **objectKey asla dönmez.**
   - `GET {id}/artifact` — revizyondan `contentId`'yi çöz → FU01 `GET objects/{contentId}/content`'i (kullanıcı token forward) proxy'le → PDF stream (doğru Content-Type + bodiless/404 guard). **contentId istemciden GİRDİ olarak alınmaz** (revizyon id'den türetilir; FU01 non-leakage korunur).
6. **NuGet:** `PDFsharp` + `PDFsharp-MigraDoc` (veya `PdfSharpCore`+`MigraDocCore`) **6.x, MIT**, net-hedefe uygun; CrmService.Infrastructure.csproj'a additive.
